# 何子文 · 视觉作品集

视觉设计、产品渲染、AIGC 和产品视频作品集。

访问网站：https://h15057605391-ux.github.io/heziwen-visual-portfolio/

此仓库包含纯静态展示版，可通过 GitHub Pages 从 main 分支根目录发布。

## 文件结构

- index.html：页面、样式和交互
- media/：图片、字体、视频和软件图标
- downloads/portfolio.pdf：离线作品集
- .nojekyll：按原样发布静态资源

## 更新

替换展示素材或修改 index.html 后推送到 main，GitHub Pages 会自动更新。所有资源使用相对路径，兼容项目站点子目录。

网站中使用的开源字体、图标和样机素材说明保留于 HTML 内的许可证声明中。
